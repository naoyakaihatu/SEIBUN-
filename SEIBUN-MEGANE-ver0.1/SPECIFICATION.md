# SEIBUNメガネ ver0.1 仕様概要

## 1. プロダクト方針

「肌を知る。成分を見る。」を中心に、1画面1目的・少ない情報量・大きな選択肢を基本UIとする。特定サイトの画面を複製せず、1問1画面・進捗表示・余白の多い診断UXを独自デザインで採用する。

## 2. 簡単肌チェック

5問、約60秒。回答から `dry / balance / oily` の3タイプに整理する。

- うるおい補給タイプ
- バランス調整タイプ
- 皮脂コントロールタイプ

結果にはタイプ説明とおすすめ成分TOP3を表示し、次のステップとして「じっくり32タイプ診断」を大きく案内する。

## 3. じっくり肌チェック

基本16問＋現在の季節3問。最後に年齢・性別を任意入力する。

4軸：
1. うるおい ↔ 皮脂
2. ゆらぎ ↔ 安定
3. 色ムラケア ↔ 維持
4. ハリケア ↔ 維持

4軸の2値組み合わせで16基本タイプを作る。男性・女性を任意選択した場合は、基本タイプを変えずに成分優先度を小さく補正し、`M01〜M16` / `F01〜F16` の最大32プロフィールとして表示する。性別未回答/その他は16基本タイプとして表示する。

多軸型の肌分類という考え方は参考にするが、Baumann Skin Type Questionnaireそのものは使用せず、質問・採点・タイプ名・説明は独自仕様とする。

## 4. おすすめ成分

肌プロフィールから成分候補を順位付けし、TOP5を表示する。各カードには以下を表示する。

- 成分名
- 短い一般向け説明
- なぜ今回おすすめなのか
- 成分辞典へのリンク

おすすめ順位は肌回答を主とし、年齢・性別・季節は小さな補助情報として扱う。

## 5. 成分読み取り

入力手段：
- ブラウザ内カメラ
- 端末内の写真
- 成分テキスト貼り付け/手入力

OCR：Tesseract.js 5.1.1（jpn+eng）。通常画像で認識し、認識成分が少ない場合のみコントラスト処理した2回目を行う。

カメラ明るさアシストは中央領域を約800msごとに測定し、暗すぎ/明るすぎが3回連続した時だけ控えめに警告する。初期値は平均輝度60未満 / 230超。公開前の実商品QAで調整する。

## 6. OCR待機画面

OCR開始時は専用画面へ切り替える。

- 読み取り状況
- 進捗率
- 大きな成分ミニ知識
- 8秒ごとにミニ知識を切り替え
- 丸みのある日本語フォント候補を優先

## 7. 商品おすすめ目安

内部一致度から5段階の星へ変換する。

- 82以上：★★★★★
- 68〜81：★★★★☆
- 42〜67：★★★☆☆
- 34〜41：★★☆☆☆
- 33以下：★☆☆☆☆

星2・星4の帯を狭め、1/3/5を中心にする。認識成分が3件未満の場合は暫定表示とし、最大3相当までに抑える。星は安全性・効果の保証ではない。

## 8. 成分辞典

統合成分DB 416件。検索対象は表示名、INCI、別名、カテゴリ、目的。成分詳細では、一般向け説明、役割、肌との関わり、注意点、確認済みメーカー公式情報があれば表示する。

## 9. 保存

通常はsessionStorage。ユーザーが「この端末に保存」を明示操作した場合のみ、肌プロフィールと履歴をlocalStorageにも保存する。

- 端末保存ON/OFF
- 履歴削除
- 全データリセット

## 10. 法務・表現

- 医学的診断と表現しない
- 一般化粧品で成分名だけから「有効成分」と断定しない
- 「効く」「治る」「絶対合う」「安全」等の断定を避ける
- 星評価を安全性スコアにしない
- 個人の反応歴や実際の製品表示を優先する
