# SEIBUNメガネ ver0.1

実使用を前提に、旧版の公開機能を整理して作り直した静的Webアプリです。

## 主な機能

- 5問・約60秒の簡単肌チェック → 3タイプ
- 16基本タイプ × 男性/女性プロフィール = 最大32プロフィールのじっくり肌チェック
- 現在の季節に合わせた3問を自動追加
- 年齢・性別は最後に任意入力（回答内容が判定の主役）
- 肌タイプごとのおすすめ成分 TOP5 と、成分ごとの説明・おすすめ理由
- 32プロフィール用の差し替え可能なSVG仮イラスト
- スマホカメラ / 写真選択 / 手入力から全成分を読み取り
- OCR待機を専用画面化し、8秒間隔で大きな成分ミニ知識を表示
- 読み取った成分から、自分向けの星5段階おすすめ目安を表示
- 星2・星4は境界帯を狭くし、星1・3・5を中心に表示
- 結果内の成分をタップして成分辞典へ移動
- 416件の読み取り・辞典データ
- sessionStorageによる一時利用 / 明示操作でlocalStorageへ端末保存
- 履歴、端末保存解除、全データリセット
- HTTPS環境でのブラウザ内カメラと明るさアシスト

## コード整理

旧版のカルテ、JAN、商品検索、旧ルート、旧分析資料、旧バージョン互換コードはver0.1には含めていません。
公開アプリのコードは次の構成に整理しています。

- `index.html`：公開HTMLは1ファイル
- `styles.css`：UI
- `js/core.js`：状態・保存・画面遷移
- `js/diagnosis.js`：肌チェック
- `js/ingredients.js`：成分検索・おすすめ・評価
- `js/ocr.js`：カメラ・OCR
- `js/app.js`：公開画面
- `data/diagnosis.js`：質問・タイプ・おすすめ成分定義
- `data/ingredients.js`：統合済み成分DB
- `data/config.js`：調整値

## 公開方法

Cloudflare Pagesなどの静的ホスティングにフォルダ内容をそのまま公開できます。ビルドは不要です。

カメラの `getUserMedia()` は公開時にHTTPSが必要です。OCRはTesseract.jsをCDNから読み込むため、初回利用時はインターネット接続が必要です。

## 32タイプのイラスト差し替え

`assets/types/` に `F01.svg`〜`F16.svg`、`M01.svg`〜`M16.svg` の仮イラストを配置しています。将来作成したイラストを同じファイル名で置き換えれば、コードを変更せず差し替えられます。

## 注意

肌タイプチェックは医学的診断ではありません。成分・星評価も商品の効果や安全性を保証するものではなく、質問回答と成分表示を整理するための参考情報です。
