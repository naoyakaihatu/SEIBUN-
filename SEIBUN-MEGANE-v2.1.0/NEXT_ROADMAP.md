# NEXT ROADMAP — SEIBUNメガネ

## 1. 実商品OCRベンチマーク
実際の化粧品パッケージを最低50〜100商品で検証し、成分単位Precision / Recall、完全一致商品率、撮り直し率を記録します。

SEIBUNメガネでは「間違った成分を確定表示しない」ことを優先し、PrecisionをRecallより重視します。

## 2. 成分辞典の根拠整備
詳細成分を増やす際は、表示名称・INCI・別名・分類・一般的な配合目的・注意点・確認先をセットで管理します。

## 3. カメラ補助の高度化
現行v2.0.0は枠表示と明るさ/強い反射の簡易アシストです。将来はブレ検知・文字領域推定・自動トリミングを検討します。

## 4. 公開ユーザーテスト
20〜50人程度で、悩み1タップ→撮影→星評価までの離脱率、OCR失敗率、結果理解度を確認します。

## 5. 会員・クラウド保存（将来）
現状は端末内保存のみです。複数端末同期が必要になった段階でAuth / DB / 削除機能 / プライバシー表示を再設計します。

## 6. 商品DB / JAN（保留）
商品DBの網羅性と更新コストが大きいため、v2.0.0では実装しません。データ維持体制が整った段階で再検討します。

## 7. 収益化（将来）
アフィリエイト等を導入する場合も、広告報酬と星評価ロジックは分離します。PR表示を明確にし、法務表示を再確認します。
