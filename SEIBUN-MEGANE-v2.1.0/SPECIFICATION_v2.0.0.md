# SEIBUNメガネ v2.0.0 仕様書

更新日: 2026-09-08

## 1. サービス概要

### 1.1 サービス名
SEIBUNメガネ

### 1.2 コンセプト
**成分を見ると、コスメが選びやすくなる。**

化粧品の全成分表示をカメラまたは画像から読み取り、ユーザーが今いちばん気になる肌悩みと照らして、商品選びの参考になる情報を星5段階と日常語で整理するWebアプリです。

### 1.3 主目的
- 化粧品成分に詳しくないユーザーでも、成分表を撮るだけで概要を理解できるようにする
- 「今の悩みとの方向性」を星5段階で素早く把握できるようにする
- 専門用語やOCR失敗による離脱を減らす
- 気になった成分を成分辞典で深掘りできるようにする

### 1.4 v2.0.0で対象外とした機能
- SEIBUNカルテ
- 商品ライブラリ
- JANコード検索
- 商品名検索DB
- 会員登録
- クラウド同期
- 有料プラン
- アフィリエイトリンク

これらはメイン体験を複雑にしないため、公開版から外しています。

## 2. UX基本方針

### 2.1 最短体験
1. 今いちばん気になる肌悩みを1タップ
2. 商品の全成分表示を撮影
3. 星5段階のおすすめ目安と理由を見る

長い肌診断を結果表示前に必須にしません。

### 2.2 離脱防止方針
- 初回入力は1タップのみ
- OCR失敗時に行き止まりを作らない
- 専門的な「判定信頼度」「判定保留」を公開結果の主表示に使わない
- 情報不足時は「次に何をすればよいか」を表示する
- じっくり肌診断は任意機能として後から利用できる
- 結果後に「ほかの商品も試す」を大きく表示する
- 保存は会員登録を要求せず、ユーザーが明示的に選べる

### 2.3 デザイン方針
- マスコット画像は使用しない
- カード、アイコン、短い見出しで視認性を確保
- PC / スマートフォンで同じ情報設計を使用
- スマートフォンでは縦積み、PCでは横並びを基本とする

## 4. Home仕様

### 4.1 ファーストビュー
表示内容:
- SEIBUNメガネ
- 「成分を見ると、コスメが選びやすくなる。」
- 1タップ悩み選択
- 成分表撮影CTA

### 4.2 1タップ悩み
以下から1つ選択します。

- 乾燥
- 毛穴・皮脂
- シミ・くすみ
- ハリ
- 肌荒れ・赤み
- 刺激・敏感

選択すると、内部で即時用の簡易肌プロフィールを生成します。

### 4.3 即時プロフィール
1タップ選択を、内部の肌軸へ変換します。

例:
- 乾燥 → 乾燥軸を高く設定
- 毛穴・皮脂 → 毛穴・皮脂軸を高く設定
- 刺激・敏感 → 敏感・肌荒れ軸を高く設定

これは医療診断ではなく、商品結果を「今の悩み」に寄せて表示するための簡易設定です。

## 5. メガネ / 撮影仕様

### 5.1 撮影方法
- ブラウザ内カメラ
- 端末内画像選択
- 手入力
- テキスト貼り付け

### 5.2 ブラウザ内カメラ
`navigator.mediaDevices.getUserMedia()` を使用します。

推奨:
- 背面カメラ `facingMode: environment`
- HTTPS環境必須

### 5.3 枠合わせUI
カメラ映像上に「全成分をこの枠へ」のオーバーレイを表示します。

現行v2.0.0では枠は**視覚的な撮影ガイド**です。文字領域をリアルタイム認識して枠内判定する機能ではありません。

### 5.4 リアルタイム明るさアシスト
カメラ映像を縮小Canvasへ描画し、平均輝度を簡易計測します。

現行閾値:
- 平均輝度 72未満 → 「少し暗いです」
- 平均輝度 218超 → 「反射が強いかも」
- それ以外 → 「明るさOK」

確認周期は約650msです。

### 5.5 カメラ失敗時
カメラAPIが使えない / 権限が得られない場合、画像選択へ切り替えられます。

## 6. OCR仕様

### 6.1 OCRエンジン
Tesseract.js 5.1.1

対象言語:
- 日本語
- 英語

### 6.2 OCR処理フロー
1. 元画像を読み取り
2. 成分欄向けクロップ + コントラスト処理
3. 読み取り数が少ない場合、中央領域 + 二値化処理
4. 複数パス結果を統合
5. 成分辞書と照合
6. 曖昧候補を除外
7. 分析へ渡す

### 6.3 辞書照合
対応:
- 日本語表示名称
- INCI
- 英語名
- 登録済み別名
- 全角 / 半角
- 記号差
- 一意に判断できる範囲のOCR表記ゆれ

採用しないもの:
- 複数候補が近い曖昧一致
- 根拠のない推測補完
- 短い語を無理に別成分へ変換する処理

### 6.4 OCR待機画面
待機中に以下を表示します。
- 進捗バー
- 現在の処理段階
- 成分ミニ知識

成分ミニ知識は12件の候補からランダム開始し、約2.6秒ごとに切り替えます。

例:
- グリセリンは保湿目的で広く使われる
- ビタミンC系には複数の表示名称がある
- 同じ成分でも配合量や組み合わせで使用感が変わる

### 6.5 OCR失敗時のフォールバック
解析失敗時に即時表示:
- もう一度撮る
- 手入力する
- テキストを貼る

文字は読めたが成分を確定できない場合:
- 撮り直す
- OCR文字列を手動修正
- テキストを貼る

## 7. 成分分析仕様

### 7.1 内部分析
内部では従来の0〜100スコアを保持します。

評価に使用する主な要素:
- 肌悩み / 肌軸との一致
- 成分ごとの目的重み
- 敏感傾向時の確認ポイント
- 登録された反応歴
- 成分根拠レベル
- OCR / 辞書照合品質
- 判定可能成分数

### 7.2 内部スコアと公開表示の分離
内部スコアは公開画面で100点満点として主表示しません。

公開表示は星5段階です。

| 内部スコア | 公開星 | 表現 |
|---:|---|---|
| 80以上 | ★★★★★ | かなりおすすめ候補 |
| 65〜79 | ★★★★☆ | おすすめ候補 |
| 50〜64 | ★★★☆☆ | 比較しながら選ぶ |
| 35〜49 | ★★☆☆☆ | 別候補も比較 |
| 34以下 | ★☆☆☆☆ | 別候補を優先 |

### 7.3 正式スコアの表示条件
通常の全成分分析では、判定可能成分数・カバー率・内部信頼度が一定条件を満たした場合に正式スコアを生成します。

内部ロジック:
- 判定可能成分 3件以上
- カバー率10%以上、または判定可能成分6件以上
- 内部信頼度50以上

### 7.4 暫定星
正式スコアが作れなくても、判定可能な成分が1件以上ある場合は、その成分群の適合度平均を使い**暫定星**を表示できます。

暫定値は35〜79に制限します。

公開例:
- 「暫定：おすすめ候補」
- 「成分の一部から見た暫定目安」
- 「全成分を撮り直すと精度UP」

### 7.5 成分情報がほぼない場合
判定可能成分が0件の場合、星を無理に生成しません。

「判定保留」と表示する代わりに:
- もう一度撮ると結果が出しやすい
- 成分欄全体を撮る
- 手入力
- テキスト貼り付け

を表示します。

### 7.6 公開画面に出さない専門指標
- 判定信頼度という数値ラベル
- 判定保留という専門語

内部では品質管理のため計算を維持します。

## 8. 結果画面仕様

表示優先順位:
1. 星5段階
2. 一言結論
3. 読み取り状況を日常語で表示
4. 良いところ
5. 確認したいところ
6. 次の商品で見たい成分候補
7. 次のアクション
8. 全成分 / 評価前提などの詳細情報

### 8.1 結果の一言
- かなりおすすめ候補
- おすすめ候補
- 比較しながら選ぶ
- 別候補も比較

反応歴との一致がある場合は星より先に確認を促します。

### 8.2 良いところ
今の悩みとの方向性が比較的高い成分を表示します。

各成分はタップ可能で、成分辞典の詳細ページへ移動します。

### 8.3 確認したいところ
「危険成分」ではなく、以下のような確認理由を表示します。
- 敏感傾向では刺激感を確認したい
- 過去の反応歴と重なる
- 今の優先目的との一致は低め

### 8.4 次の商品で見る成分
今の悩みとの方向性が合いやすく、現在の商品に含まれていない成分候補を最大4件表示します。

「不足成分」と断定しません。

### 8.5 結果後のCTA
- ほかの商品も試す
- じっくり肌診断で詳しくする
- この結果を端末に保存 / 履歴を見る

「ほかの商品も試す」では現在の悩み設定を保持します。

## 11. 履歴・保存仕様

### 11.1 通常利用
保存先: `sessionStorage`

対象:
- 肌プロフィール
- 選択した悩み
- 解析履歴

タブを閉じると原則消えます。

### 11.2 明示的な端末保存
ユーザーが「この端末に保存」を押した場合のみ `localStorage` へコピーします。

保存対象:
- 肌プロフィール
- 選択した悩み
- 解析履歴

以後、同じブラウザでは更新もlocalStorageへ同期します。

### 11.3 保存解除
「端末保存を解除」:
- localStorageの対象データと保存ONフラグを削除
- 現在開いているタブのsessionStorageは残す

### 11.4 全データ削除
履歴画面から以下を一括削除できます。
- sessionStorageの対象データ
- localStorageの対象データ
- 保存ONフラグ

削除後はHomeへ戻ります。

### 11.5 クラウド
使用しません。会員登録もありません。

## 14. 法務・表示方針

### 14.1 星評価の意味
星は、入力された肌悩みと確認できた成分の一般的な配合目的を整理した参考目安です。

以下は示しません。
- 商品の安全性
- 品質
- 治療効果
- 医学的適合性
- アレルギーの有無

### 14.2 表現ルール
使用する表現:
- 目的との方向性
- おすすめ候補
- 比較しながら選ぶ
- 確認したい
- 成分構成上の参考

避ける表現:
- 絶対合う
- 安全
- 危険
- 治る
- シミが消える
- 毛穴が消える

### 14.3 有効成分
成分名だけから、その商品で「有効成分」として扱われているとは断定しません。実際の商品表示を優先します。

### 14.4 OCR
実際の容器表示・メーカー公式表示を優先します。

## 16. 成分データ方針

### 16.1 根拠レベル
- Level 3: メーカー公式確認
- Level 2: 公的 / 業界標準DB等
- Level 1: 一般情報
- Level 0: OCR名称辞書のみ

正式な内部分析には原則Level 2以上を使用します。

### 16.2 方針
「OCRで名前が読めること」と「評価へ使えること」を分離します。

曖昧な候補を無理に評価へ入れません。

## 18. 今後の課題

優先順位:
1. 実商品50〜100件のOCRベンチマーク
2. 成分辞典の根拠整備
3. カメラ補助の高度化（ブレ検知 / 文字領域推定等）
4. 小規模ユーザーテスト
5. 必要になった段階でクラウド保存

商品DB / JANはデータ維持コストが大きいため保留します。
