# TRUST DESIGN — SEIBUNメガネ v2.0.0

## 基本方針
SEIBUNメガネは「多く当てる」より、間違っている可能性のある成分を確定情報のように見せないことを優先します。

## OCR
画像OCRと成分辞書照合は別工程です。和名 / INCI / 英語名 / 登録済み別名 / 表記ゆれを照合し、曖昧な候補は採用しません。

## 根拠レベル
- Level 3: メーカー公式確認
- Level 2: 公的・業界標準DB等で確認
- Level 1: 一般情報
- Level 0: OCR名称辞書のみ

内部の正式評価には原則Level 2以上を使います。

## 公開結果
ユーザー向けには専門的な「判定信頼度」「判定保留」を主表示せず、
- 十分読み取れた
- 大部分を読み取れた
- 一部からの暫定目安
- 撮り直すと結果が出しやすい
のように次の行動が分かる言葉へ変換します。

## 星評価
星は、選択した肌悩みと確認できた成分の一般的な配合目的を照らし合わせた参考目安です。安全性、品質、治療効果、アレルギーの有無を示しません。

## データ不足
判定可能な成分が1件以上ある場合は暫定星を表示できます。ただし正式スコアではないため「暫定」と明記し、35〜79の範囲に制限します。判定可能成分が0件なら星を作らず、撮り直し/手入力/貼り付けを案内します。
