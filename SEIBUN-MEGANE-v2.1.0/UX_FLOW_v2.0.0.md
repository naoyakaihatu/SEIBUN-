# UX FLOW — v2.0.0

## 最短ルート

Home
→ 悩みを1タップ
→ 成分表を撮影
→ OCR待機中に成分ミニ知識
→ 星5段階結果
→ ほかの商品を試す / 成分辞典 / じっくり肌診断

## 初回離脱を抑える設計

- 撮影結果を見る前に長い診断を挟まない
- 最初の入力は1タップだけ
- OCR失敗で行き止まりを作らない
- 専門用語「判定保留」「判定信頼度」を公開結果から外す
- 読み取り不足は「次に何をすればいいか」で表示する
- じっくり診断は結果後に任意で促す

## リピート

結果
→ ほかの商品も試す
→ 同じ悩み設定のまま撮影
→ 結果

## 端末保存

結果 / 履歴
→ この端末に保存
→ localStorageへコピー
→ 次回同じブラウザで復元

保存しない場合は、タブを閉じると一時データが消えます。
