# SEIBUNメガネ

化粧品の全成分表示を撮影し、今の肌悩みに合わせて星5段階で整理するWebアプリです。

## v2.1.0 UI方針

「1画面1目的」を優先し、初期画面は以下だけに絞っています。

- SEIBUNメガネの名称
- 一言説明
- 「成分表をスキャンする」メインCTA
- 「使い方」「成分辞典」の小さな補助リンク

ホームでは上部ヘッダー・下部ナビ・フッターも隠し、最初の行動を1つに集中させます。

## 主要画面

- ホーム: スキャン開始のみを主役化
- 撮影: カメラを主役にし、手入力等は「うまく撮れないとき」に収納
- OCR待機: 進捗＋短い成分知識を静かに表示（5秒間隔）
- 結果: 星・結論・「ほかの商品も試す」を先に表示。理由・成分一覧は折りたたみ
- 成分辞典: 検索欄を最初に表示し、成分カードは名称＋一言だけ
- 成分詳細: 一言解説を先に表示し、根拠等は折りたたみ
- 履歴: 結果一覧を主役にし、保存・リセットは設定内へ収納

## 保存

通常は sessionStorage の一時保存です。「この端末に保存」を押した場合のみ localStorage に保持します。
