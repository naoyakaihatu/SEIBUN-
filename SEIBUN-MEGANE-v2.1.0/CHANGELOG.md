## 2.1.0 — Minimal UI

- 案Aの超シンプルな初期画面へ変更
- ホームではメインCTA「成分表をスキャンする」だけを主役化
- 1画面1目的のデザインに統一
- 撮影画面・結果画面・成分辞典・履歴・肌設定を簡素化
- 結果の理由・全成分・評価説明を折りたたみに移動
- 結果画面から現在の悩みを変更して再判定できる導線を追加
- OCR成分ミニ知識を短文化し、切替を5秒間隔へ変更
- 白・グレー・緑を中心に色数と装飾を削減

# CHANGELOG

## 2.0.0 — internal

### Brand / Scope
- SEIBUN NAVIから「SEIBUNメガネ」へ名称変更
- カルテ機能を公開版から削除
- 商品ライブラリを公開版から削除
- メガネ・成分辞典・履歴に集中

### First-use UX
- 商品結果前のクイック/じっくり二択を廃止
- 初回入力を「一番気になる悩み」1タップへ短縮
- じっくり肌診断は結果後の任意機能へ移動

### Camera / OCR
- ブラウザ内カメラを追加
- 成分欄の枠合わせオーバーレイ
- 明るさ・強い反射のリアルタイムアシスト
- OCR待機中にランダム成分ミニ知識を表示
- OCR失敗時の撮り直し / 手入力 / テキスト貼り付けを強化

### Result
- 100点表示より星5段階を優先
- 「判定保留」「判定信頼度」を公開結果から撤去
- データが少ない場合は暫定星を表示
- 情報がほぼない場合は星を無理に出さず、次アクションを表示
- 「ほかの商品も試す」をメイン導線に維持

### Dictionary
- 成分辞典をメインナビへ追加
- 日常語タグを強化
- 成分名タップでフルページ解説へ遷移

### Storage
- 通常はsessionStorage
- 「この端末に保存」を押した場合のみlocalStorageへ保存
- 保存後の更新は同じブラウザへ自動同期
- 保存解除 / 全データ削除を追加
