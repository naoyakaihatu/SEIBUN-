# SCORING DESIGN — SEIBUNメガネ v2.0.0

## 基本方針

内部分析は従来の0〜100スコアを維持します。ユーザー画面では100点満点を主表示にせず、星5段階へ変換します。

### 星変換

- 80以上 → ★★★★★
- 65〜79 → ★★★★☆
- 50〜64 → ★★★☆☆
- 35〜49 → ★★☆☆☆
- 34以下 → ★☆☆☆☆

## データ不足時

内部の正式スコアが非表示になる条件でも、判定に利用できる成分が1件以上ある場合は、その成分群の適合度平均から暫定スコアを生成し、35〜79の範囲に制限して「暫定」と表示します。

判定可能な成分が0件の場合は星を出しません。「判定保留」ではなく、撮り直し・手入力等のアクションを表示します。

## 信頼度

内部ではOCR品質、辞書一致、根拠情報、判定可能成分数を使って算出します。ただし公開結果では「判定信頼度」という専門的な数値を主表示しません。

公開画面は次のように変換します。

- 成分情報は十分読み取れています
- 大部分を読み取れています
- 成分の一部から見た暫定目安
- 全成分を撮り直すと精度UP

## 注意

星評価は商品の安全性・品質・医学的適合性を示しません。
